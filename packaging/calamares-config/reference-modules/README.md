# Referencias de módulos para laboratorio

Este directorio es **documental y no activable**. Sus archivos terminan en `.conf.reference`, no se incluyen en el paquete `danenone-calamares-config` y no son leídos por Calamares. No hay un `settings.conf` ejecutable en este árbol.

Las referencias describen una futura configuración de laboratorio. Sólo podrán convertirse en `/etc/calamares/settings.conf` y `/etc/calamares/modules/*.conf` después de crear una ISO distinta de Plasma RC1, validar su preflight y completar las pruebas con discos `qcow2`.

No contienen contraseñas, tokens, identificadores DaneDesk, rutas de discos físicos, `shellprocess`, `contextualprocess`, `webview`, telemetría ni GeoIP.
