# Cloud Danenone Devices v0.1.0-26.08-23.53

Primera entrega del agente Fluthin `influent.cloudmitiger-agenttask` para
Danenone. Incluye activación por código alfanumérico temporal, consulta de
estado DaneDesk mediante HTTPS, persistencia local con permisos restrictivos,
registro de bloqueo recuperable y verificación local de OTP de seis dígitos.

La versión no recolecta ubicación ni transmite identificadores de hardware sin
transformar. Las acciones de recuperación se mantienen vinculadas a la
autorización del propietario en Foundstore.
